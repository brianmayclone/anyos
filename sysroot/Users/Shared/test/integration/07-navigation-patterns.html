Navigation Patterns

A showcase of common navigation UI patterns, each implemented with HTML and CSS.

Expected Rendering

  • Pattern 1 (Horizontal Nav): A dark blue bar with "DevHub" brand on the left and five links on the right. The "Home" link should have a teal bottom border (active indicator). Links should be horizontally spaced within the bar. Hovering changes link color.
  • Pattern 2 (Breadcrumb): A horizontal trail: Home > Documentation > Components > Navigation > Breadcrumbs. Each level separated by a ">" character. All items except the last are links (muted color). The last item ("Breadcrumbs") is bold white text, not a link.
  • Pattern 3 (Tabs): Five horizontal tabs in a row with a bottom border line. The "Overview" tab is active (teal text + teal bottom border). Below the tabs, a content panel shows text for the active tab. Clicking a different tab (via JS) should switch the visible panel and move the active indicator.
  • Pattern 4 (Pagination): Two pagination examples. The simple one shows "Prev" (disabled/grayed), pages 1-5 (1 is active/filled teal), and "Next". The extended one shows pages 1-5, an ellipsis "...", pages 24-25, with page 4 active. All page buttons are equal-sized squares except Prev/Next which are wider.
  • Pattern 5 (Sidebar Nav): Two-column layout: a 240px sidebar on the left with a content area on the right. The sidebar has section headers ("Getting Started", "Components", "Advanced") with links below. "Buttons" is the active item. Sub-items are indented (Primary, Secondary, Icon are indented once; "Indeterminate" under Checkbox is indented twice). Horizontal dividers separate sections.
  • Pattern 6 (Pill Nav): Vertical stack of pill-shaped links, 200px wide. "Account Settings" is active (filled teal pill). Others are transparent with text color.
  • Pattern 7 (Bottom Tab Bar): Five equal-width items in a horizontal bar, each with a small square icon placeholder and a text label below. "Home" is active (teal icon and text). This simulates a mobile bottom navigation.
  • Overall: Each navigation pattern is contained in its own bordered section box with a header describing what it is. All patterns should be clearly separated and render independently without interfering with each other.
