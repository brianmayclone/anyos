Expected Rendering

  • Page layout: Centered form container (max-width 720px) with comfortable padding. Page title and description centered at the top.
  • Fieldsets: Three grouped fieldsets ("Personal Information", "Account Details", "Preferences"), each with a bordered box, rounded corners, darker background, and a legend label in teal that appears to overlap the top border.
  • Two-column rows: First/last name fields are side by side using flexbox (two equal-width fields with a gap). Date/website also two columns. Other fields are full width.
  • Input styling: All text inputs, email, password, textarea, and select elements are full-width within their fieldset, with dark backgrounds, subtle borders, and teal focus borders.
  • Labels: Each input has a bold label above it. Required fields show a red asterisk. Optional fields show "(optional)" in gray.
  • Checkboxes: Notification preferences shown as a vertical list of checkboxes with labels. "Email notifications" and "Push notifications" are pre-checked.
  • Radio buttons: Theme preference and language are radio button groups. "Dark mode" and "English" are pre-selected.
  • Password strength: Four small bars below the password input that fill with color as the password gets stronger (red=weak, yellow=fair, green=strong). Label text updates dynamically.
  • Buttons: Two buttons right-aligned: gray "Reset" button and teal "Create Account" button.
  • Validation (JS): On submit, empty required fields get a red border and show inline red error messages. A summary banner appears below the buttons. If all valid, a green success banner appears. The form should NOT actually submit (preventDefault).
  • Help text: Small gray text appears below the bio textarea ("Maximum 500 characters") and username input with format requirements.
