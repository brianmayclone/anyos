Surf.app is a custom web browser built for anyOS. It includes an HTML parser, CSS layout engine, and JavaScript runtime, all implemented from scratch to run on a bare-metal operating system.

Surf.app supports HTML5 elements including headings, paragraphs, lists, tables, forms, links, images (via data URIs), and semantic elements. The parser handles both well-formed and some malformed markup.

The CSS engine supports block layout, inline layout, flexbox, and CSS Grid. Properties like margin, padding, border, background colors, font sizes, and positioning (static, relative, absolute) are implemented.

Yes, a JavaScript engine is integrated with DOM bindings. You can use document.getElementById, addEventListener, createElement, and modify element styles and content dynamically. This page itself uses JavaScript for all its interactive widgets.

Place your HTML files in the sysroot test directory and open them in Surf.app. The test suite includes individual HTML, CSS, and JS tests as well as integration tests like this one that combine all three technologies.

Expected Rendering

  • Counter: Large number (initially "0") centered between circular minus and plus buttons. Below: "Reset" and "Random" small buttons. Clicking + increments, - decrements, Reset sets to 0, Random picks 1-100. The number updates immediately on each click.
  • To-Do List: Text input with "Add" button at the top. Below, a list of pre-seeded items. Each item has a checkbox (square div), text, and delete button (X). Clicking the checkbox toggles strikethrough on the text and fills the checkbox teal. Clicking X removes the item. Stats line shows total items and completed count. Typing in the input and pressing Enter or clicking Add creates a new item.
  • Calculator: A display area showing "0" with a 4x5 grid of buttons below. Number buttons (0-9) in dark gray, operator buttons (+,-,x,/) in dark blue with teal text, equals button in teal, and C (clear) in dark red. The "0" button spans 2 columns. A sub-display above the main number shows the pending operation (e.g., "5 +"). Clicking numbers builds the display value; clicking an operator stores the first operand; clicking = computes and shows the result.
  • Theme Switcher: Row of theme buttons with color swatches (small circles). Clicking a button updates the preview area below: background color, text color, and accent color change to match the selected theme. The active button has a teal border. Five themes available: Default Dark, GitHub Dark, Dracula, Solarized Light, Catppuccin.
  • Accordion: Five collapsible sections. Each has a clickable header with an arrow indicator. The first section ("What is Surf.app?") starts open. Clicking a closed header opens it and closes any previously open section. The arrow rotates when open. Content appears below the header with a top border separator.
  • Overall: All five widgets are contained in separate bordered section boxes stacked vertically. Each responds to click events with immediate visual feedback. No page reloads occur -- all interactions are handled by JavaScript DOM manipulation.
