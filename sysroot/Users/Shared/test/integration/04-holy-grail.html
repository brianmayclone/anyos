The Holy Grail Layout Pattern

The "Holy Grail" layout is a classic web design pattern featuring a header, footer, and three columns in between. The center column contains the main content and is wider than the two sidebars. This layout has historically been challenging to implement, but flexbox makes it straightforward.

How This Layout Works

The body uses display: flex; flex-direction: column with min-height: 100vh to ensure the page fills the viewport. The middle section (.holy-grail) uses flex: 1 to take remaining space and display: flex for horizontal columns.

Column Sizing

The left and right sidebars have width: 200px and flex-shrink: 0 so they do not compress. The main content uses flex: 1 to fill all remaining horizontal space.

Key Characteristics

  • Header spans the full width of the page
  • Footer spans the full width and stays at the bottom
  • Three columns between header and footer
  • Center column is fluid (takes remaining width)
  • Side columns are fixed width (200px each)
  • All three columns have equal height (flexbox stretch)
  • Footer sticks to bottom even when content is short

Common Variations

The holy grail can also be implemented with CSS Grid using grid-template-columns: 200px 1fr 200px. The flexbox approach shown here is equally valid and has broader browser support. Some implementations use order to allow the main content to come first in the HTML source for SEO and accessibility benefits.

Content Reflow Test

This card tests that content in the center column wraps correctly and does not extend into or overlap with the sidebars. The center column has min-width: 0 to prevent flex items from overflowing their container when content is wider than available space.

Expected Rendering

  • Header: Full-width bar at the top spanning all three columns. Contains page title on the left and navigation links on the right. Dark blue background.
  • 3-Column layout: Between header and footer, three columns fill the page. Left sidebar (200px), main content (remaining space), right sidebar (200px). Implemented with flexbox.
  • Equal-height columns: All three columns should extend to the same height, regardless of their individual content length. This is the default behavior of flex items (align-items: stretch).
  • Left sidebar: Fixed 200px width, contains a vertical list of navigation links with one marked as active (highlighted background and teal text). Should not shrink below 200px.
  • Main content: Center column that flexes to fill remaining width. Contains heading, paragraphs, content cards with dark backgrounds, lists, and code snippets. Text should wrap within the column without overflowing into sidebars.
  • Right sidebar: Fixed 200px width with widget boxes (stats, recent posts, tag cloud, about text). Tags should wrap in a flex-wrap row.
  • Footer: Full-width bar at the very bottom. If the content is shorter than the viewport, the footer should still be at the bottom of the viewport (not floating in the middle). Copyright on the left, links on the right.
  • Column borders: Left sidebar has a right border, right sidebar has a left border, creating visual separation between all three columns.
  • No overlap: The sidebars and main content should never overlap. Content in the main area should never extend under or over the sidebars.
