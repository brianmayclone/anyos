Expected Rendering

  • Top navigation: Full-width dark blue bar with logo (teal square + "AdminPanel") on the left and links + circular user avatar on the right. Height ~48px, all items vertically centered.
  • Overall layout: CSS Grid with two columns -- sidebar at 220px fixed width on the left, main content filling the rest. The sidebar should extend to at least the viewport height.
  • Sidebar: Vertical navigation with section headers ("Main", "Management", "System") in uppercase small text. Links have left-border accent. The "Dashboard" link should show as active (teal color, left border highlight).
  • Stat cards: Four cards in a single row (CSS Grid 4 columns). Each card has a colored top border accent, uppercase label, large bold number, and small change indicator (green for positive, red for negative).
  • Chart + Activity: Two panels side by side in a grid. The chart panel shows vertical bars of varying height with month labels below. The activity panel shows a list of items with colored dots and timestamps.
  • Data table: Full-width table with uppercase column headers on a slightly darker background. Rows alternate between two shades. Status column shows colored badge pills. Table should span the full content width.
  • Alternating row colors: Even rows have a slightly different background than odd rows. Hover state changes the row background.
  • Professional appearance: The overall dashboard should look like a real admin interface with consistent spacing, subtle borders, and a cohesive dark color palette.
