Expected Rendering

  • Page header: Large title "Shop Components" with a subtitle in muted text below.
  • Filter bar: Horizontal row of pill-shaped filter buttons with "All" filled in teal as the active state. Other buttons are outlined. A sort dropdown appears on the far right (pushed by flex spacer). Buttons should wrap if the viewport is narrow.
  • Results info: Small text showing "Showing 9 of 247 products" on the left and "Page 1 of 28" on the right.
  • Product grid: 3 columns of product cards using CSS Grid with equal column widths. 20px gap between cards. 9 cards total = 3 rows of 3.
  • Card structure: Each card has a colored gradient image placeholder area (180px tall) at the top, followed by category label (small uppercase), product title (bold), description (muted text), star rating, and a price + button row at the bottom.
  • Card uniformity: All cards should be the same width. The description area flexes so the price/button row aligns to the bottom regardless of description length.
  • Badges: Some cards have "NEW" or sale percentage badges positioned in the top corners of the image area (absolute positioning within the image container).
  • Hover effect: Card border should change to teal color on hover (CSS :hover, no JS needed).
  • Prices: Sale items show the discounted price in teal with the original price struck through next to it.
  • Out of stock: The last card has a grayed-out "Out of Stock" button instead of the normal teal "Add to Cart".
  • Load more: Centered outlined button below the grid.
  • Card corners: All cards have border-radius: 12px with overflow: hidden so the image area respects the rounded top corners.
