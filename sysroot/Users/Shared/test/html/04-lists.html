Test 04: Lists (ul, ol, dl)

Test 4.1: Basic Unordered List

Expected: A bulleted list with disc (filled circle) markers by default. Each item indented from the left. Items should be block-level within the list.
  • Apple
  • Banana
  • Cherry
  • Date
  • Elderberry

Test 4.2: Basic Ordered List

Expected: A numbered list starting from 1. Numbers should auto-increment (1, 2, 3, ...). Items should be indented and block-level.
  1. First item
  2. Second item
  3. Third item
  4. Fourth item
  5. Fifth item

Test 4.3: Nested Lists

Expected: Nested lists should be further indented. Nested ul markers typically change: disc -> circle -> square. Nested ol continues numbering independently.
  • Fruits
    • Citrus
      • Orange
      • Lemon
      • Grapefruit
    • Berries
      • Strawberry
      • Blueberry
  • Vegetables
    • Root vegetables
      • Carrot
      • Potato
    • Leafy greens

Test 4.4: Mixed Nested Lists

Expected: ol inside ul should show numbered sub-items under bulleted parents. ul inside ol should show bulleted sub-items under numbered parents. Nesting should work for any combination.
  • Unordered parent item 1
    1. Ordered child 1
    2. Ordered child 2
    3. Ordered child 3
  • Unordered parent item 2
  1. Ordered parent item 1
    • Unordered child A
    • Unordered child B
    • Unordered child C
  2. Ordered parent item 2

Test 4.5: Definition List (dl, dt, dd)

Expected: dt (term) should be displayed in a normal/bold style. dd (definition) should be indented below its term. Multiple dd for one dt should each be indented.

Test 4.6: List Items with Multiple Paragraphs

Expected: Each li can contain multiple p elements. The paragraphs should be spaced within the list item, and the bullet/number should align with the first paragraph.

  • First paragraph of item one.

    Second paragraph of item one, continuing the same list item.

  • First paragraph of item two.

    Second paragraph of item two.

    Third paragraph of item two.

  • Single paragraph item three.

Test 4.8: Ordered List Start and Reversed

Expected: The first list should start numbering at 5 (5, 6, 7). The second list should count in reverse (3, 2, 1). The third should use the value attribute for specific numbers.

start="5":

  1. Item (should be 5)
  2. Item (should be 6)
  3. Item (should be 7)

reversed:

  1. Item (should be 3)
  2. Item (should be 2)
  3. Item (should be 1)

value attribute:

  1. Item (should be 10)
  2. Item (should be 11)
  3. Item (should be 20)
  4. Item (should be 21)

Test 4.9: Lists with Inline Formatting

Expected: List items should support inline formatting elements like bold, italic, links, and code within the list item text.
  • Bold item with normal continuation
  • Italic item with normal continuation
  • Item with a link inside
  • Item with inline code inside
  • Deleted item replaced by this

Test 4.10: Edge Cases

Expected: An empty ul/ol should not display any markers or take significant space. A single-item list should display one bullet/number. An li with no text should show a marker but no text.
