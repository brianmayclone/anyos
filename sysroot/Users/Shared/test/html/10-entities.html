Test 10: HTML Entities

Test 10.1: Common Entities

Expected: Each named entity should render as its corresponding character. &amp; should show &, &lt; should show <, &gt; should show >, etc.
Entity Rendered Description
&amp; & Ampersand
&lt; < Less than
&gt; > Greater than
&quot; " Double quotation mark
&apos; ' Apostrophe / single quote

Inline test: 5 < 10 && 10 > 5 is "true".

Test 10.2: Whitespace Entities

Expected: &nbsp; should produce a non-breaking space (same width as regular space, but prevents line break). &ensp; should be an en-space (~half em). &emsp; should be an em-space (~full em width).
Entity Between Bars Description
&nbsp; | | Non-breaking space
&ensp; | | En space (half em)
&emsp; | | Em space (full em)

Non-breaking space test: these words should not break across lines individually.

Expected: Dashes, quotes, and ellipsis should render as their correct typographic characters. En dash is shorter than em dash. Smart quotes should be curly, not straight.
Entity Rendered Description

&mdash; — Em dash
&lsquo; ‘ Left single quote
&rsquo; ’ Right single quote
&ldquo; “ Left double quote
&rdquo; ” Right double quote

Usage: Pages 10–20 contain the results—which are surprising.

She said, “It’s a beautiful day,” and smiled.
