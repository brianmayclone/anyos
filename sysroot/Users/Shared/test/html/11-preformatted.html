Test 11.2: Code Block (code inside pre)

Expected: A code block (pre + code) should render in monospace with preserved whitespace. This is the standard pattern for displaying source code on web pages.
fn main() {
    let message = "Hello, anyOS!";
    println!("{}", message);

    for i in 0..10 {
        if i % 2 == 0 {
            println!("{} is even", i);
        }
    }
}

Test 11.3: Inline Code vs Code Block

Expected: Inline code (code without pre) should appear monospace within the paragraph text. The code block (pre+code) should be a separate block with preserved whitespace. Clear visual distinction between the two.

Use the println!() macro to print output. The fn main() function is the entry point.

Here is a full code block:

use std::io;

fn main() {
    let mut input = String::new();
    io::stdin().read_line(&mut input).unwrap();
    println!("You typed: {}", input.trim());
}

After the code block, the variable input holds user input.

Test 11.7: Pre with HTML Entities and Special Characters

Expected: HTML entities inside pre should still be decoded (e.g., &lt; becomes <). Raw angle brackets cannot be used directly without entities. The whitespace preservation still applies.
<html>
  <head>
    <title>Test Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>A paragraph with &amp; entities.</p>
  </body>
</html>
