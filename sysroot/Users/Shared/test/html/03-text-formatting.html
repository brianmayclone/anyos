Test 03: Text Formatting (Inline Elements)

Test 3.1: Bold Text (strong and b)

Expected: Both strong and b should render text in bold weight. They should be inline (not breaking the line). Semantically strong implies importance; b is purely visual.

This is strong text in a sentence.

This is bold text in a sentence.

Normal, strong, normal, bold, normal.

Test 3.2: Italic Text (em and i)

Expected: Both em and i should render text in italic style. They should be inline. Semantically em implies emphasis; i is purely visual.

This is emphasized text in a sentence.

This is italic text in a sentence.

Normal, emphasized, normal, italic, normal.

Test 3.3: Underline (u) and Strikethrough (s, del)

Expected: u renders with an underline decoration. s and del render with a line through the middle of the text (strikethrough).

This is underlined text in a sentence.

This is strikethrough text in a sentence.

This is deleted text in a sentence.

Underline vs strikethrough vs deleted.

Test 3.4: Code-Related Inline Elements

Expected: code, kbd, and samp should render in a monospace font. var should render in italic. All should be inline.

Inline code: let x = 42;

Keyboard input: Press Ctrl+C to copy.

Sample output: Error: file not found

Variable: The variable x is defined as y + 1.

Test 3.5: Highlight (mark) and Small Text

Expected: mark should render with a yellow/highlighted background. small should render text at a smaller font size than surrounding text.

This sentence has highlighted text in the middle.

This sentence has smaller text in the middle.

Normal text, marked, then small, then normal.

Test 3.6: Subscript (sub) and Superscript (sup)

Expected: sub should render text smaller and below the baseline. sup should render text smaller and above the baseline. Neither should significantly alter line height.

Water formula: H2O

Footnote reference: According to the study1, results were significant2.

Mathematical: x2 + y2 = z2

Chemical: C6H12O6 (glucose)

Combined: Aij tensor notation

Test 3.7: abbr, cite, dfn, q

Expected: abbr may show a dotted underline (hover shows title). cite and dfn should render in italic. q should render with quotation marks automatically added by the browser.

The WWW was invented by Tim Berners-Lee.

The book The Art of Computer Programming by Donald Knuth.

A browser is a program for viewing web pages.

She said Hello, world! and then left.

Nested quotes: He told me it works fine but I disagree.

Test 3.8: Deleted (del) and Inserted (ins) Text

Expected: del should render with a strikethrough line. ins should render with an underline. Together they can show editorial changes.

The price is $50.00 $39.99!

We will meet on Tuesday Wednesday at 3pm.

This entire sentence has been deleted.

This entire sentence has been inserted.

Test 3.9: Nested Inline Combinations

Expected: Multiple inline styles should combine. Bold+italic should show both. Bold+underline+code should show bold monospace underlined text. All combinations should render correctly.

Bold and italic

Bold and underlined

Italic and underlined

Bold, italic, and underlined

Bold code

Italic code

Underlined code

Bold italic code

Bold highlighted

Deleted italic text

Test 3.10: All Inline Elements in One Paragraph

Expected: Every inline element listed should render with its correct styling within a single paragraph. The text should flow continuously without breaking into separate lines.

Normal text, strong, bold, emphasized, italic, underlined, strikethrough, code, marked, small, subscript, superscript, kbd, samp, var, abbr, cite, dfn, quoted, deleted, inserted, and normal again.
