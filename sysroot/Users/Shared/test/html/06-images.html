Test 06: Images (img)

Test 6.1: Image with Explicit Width and Height

Expected: A 64x64 pixel red square image rendered from a data URI. The image should display at exactly 64x64 pixels as specified by the width and height attributes.

The image above should be a 64x64 red square.

Test 6.2: Image with Only Width (Height Auto)

Expected: The image should scale to 128 pixels wide with the height automatically calculated to maintain aspect ratio. Since the source is 2x2, it should render as 128x128.

The image above should be 128px wide with auto height (128px for square source).

Test 6.3: Missing Image with Alt Text

Expected: Since the image source does not exist, the browser should display the alt text as a fallback. A broken image icon may also appear. The alt text should be visible and readable.

The image above should show alt text or a broken image indicator.

Test 6.4: Image with No src Attribute

Expected: An img with no src should show a broken image placeholder or the alt text. It should not crash the browser or cause layout issues.

The element above is an img with no src. It should show alt text or a placeholder.

Test 6.5: Image with Empty Alt (Decorative)

Expected: A missing image with alt="" should show a minimal broken image indicator or nothing at all. Empty alt means the image is decorative and can be ignored for accessibility.

The image above has alt="" (empty). Minimal or no placeholder expected.

Test 6.6: Multiple Inline Images

Expected: Multiple images on the same line should be placed side by side as inline elements. They should be aligned at the baseline by default.

Three colored squares (red, green, blue) should appear side by side above.

Test 6.7: Images at Various Sizes

Expected: Three images at different sizes (16x16, 32x32, 64x64). Each should render at the specified pixel dimensions. They should appear progressively larger from left to right.

Three red squares: 16x16, 32x32, and 64x64 pixels.

Test 6.8: Image Inside a Link

Expected: The image should be clickable (wrapped in an anchor). It may show a colored border indicating it is a link. The cursor should change to pointer on hover.

The green square above is a link to the headings test page.

Test 6.9: Image Inline with Text

Expected: The image should appear inline with the text, aligned at the text baseline. The text before and after the image should be on the same line if space permits.

Here is an inline image embedded within this paragraph text. The text should flow around it naturally.
