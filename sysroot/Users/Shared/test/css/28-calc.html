CSS Test 28: calc() Expressions

Test 1: calc(100% - 200px) for Width

Expected: The first box is 100% width (full container). The second box uses calc(100% - 200px), so it should be 200px narrower than the first box. Both boxes should left-align, with the calc box visibly shorter.
Width: 100% (full container width - reference)
Width: calc(100% - 200px) - should be 200px narrower than the box above

Test 2: calc() for Positioning

Expected: Inside a relative container, the teal box is centered using calc(50% - 75px) for left, placing a 150px-wide box exactly at horizontal center. The red box is offset 20px to the right of center using calc(50% + 20px).
Centered: left=calc(50%-75px)
Offset: left=calc(50%+20px)

Test 3: calc() with Multiplication and Division

Expected: Three boxes side by side, each exactly one-third width using calc(100% / 3). They should fit perfectly in one row with no gap or overflow. Each box also has doubled padding using calc(8px * 2) = 16px padding.
calc(100%/3) width, calc(8px*2) padding - Column 1
calc(100%/3) width - Column 2
calc(100%/3) width - Column 3

Test 4: calc() with Mixed Units (px + %)

Expected: The first box has width calc(50% + 50px), which is half the container width plus 50 extra pixels. The second box has margin-left of calc(10% + 20px), so it should be indented by 10% of the container plus 20px.
Width: calc(50% + 50px) - half of container + 50px
Margin-left: calc(10% + 20px) - indented from left

Test 5: Nested calc()

Expected: Width is calc(100% - calc(50px + 50px)) = calc(100% - 100px). The box should be 100px narrower than the container. Note: Nested calc() is valid CSS but inner calc() is treated as simple grouping.
Reference: 100% width
Width: calc(100% - calc(50px + 50px)) = 100% - 100px

Test 6: calc() for Font Size

Expected: Four lines of text with increasing font sizes. Base: 16px. calc(16px + 4px) = 20px. calc(16px * 1.5) = 24px. calc(16px * 2) = 32px. Each line should be progressively larger than the one before.
Base font-size: 16px (reference)
calc(16px + 4px) = 20px
calc(16px * 1.5) = 24px
calc(16px * 2) = 32px

Test 7: Visual Alignment - Fixed + Fluid Layout

Expected: A two-column layout. The left column is fixed at 150px wide (red). The right column fills the remaining space using calc(100% - 150px) (teal). Together they should perfectly fill the container with NO gap and NO overflow.
Fixed: 150px wide
Fluid: calc(100% - 150px) wide - fills remaining space

Test 8: calc() for Height - Header + Content Pattern

Expected: A 200px tall container. The header bar is fixed at 40px. The content area uses calc(100% - 40px) = 160px to fill the remaining space. Together they should perfectly fill the 200px container.
Header: 40px fixed height
Content: calc(100% - 40px) height - fills remaining 160px of the 200px container. This area should be scrollable if content overflows.
