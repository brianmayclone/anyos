CSS Test 09: Centering with Margin Auto

Test 1: margin: 0 auto (Horizontal Centering)

Expected: A 200px-wide red box centered horizontally within the container. The left and right margins are automatically equal, placing the box in the middle. The element must have a defined width for margin: auto to center it.
width: 200px
margin: 0 auto

Test 2: Various Widths Centered with margin: auto

Expected: Three boxes of different widths (100px, 250px, 400px) all centered within the same container. Each should be horizontally centered regardless of its width.

Test 3: margin-left: auto (Push Right)

Expected: The box has margin-left: auto, which pushes it to the right edge of the container. The box should be right-aligned. This is because auto expands to fill all available space on the left.
margin-left: auto
(pushed right)

Test 4: margin-right: auto (Push Left)

Expected: The box has margin-right: auto, which pushes it to the left edge of the container. The box should be left-aligned (this is essentially the default behavior for block elements, but explicitly set).
margin-right: auto
(pushed left)

Test 5: margin: auto Without Explicit Width

Expected: A block element without an explicit width takes 100% of its parent. With margin: 0 auto but no width, the element fills the full width -- auto margins compute to 0 because there is no leftover space. The box should be full-width, NOT centered to a smaller size.
No explicit width + margin: 0 auto (full width, auto = 0)

Test 6: Centering a Fixed-Width Card

Expected: A card-like element (300px wide, with padding and border) centered in the container. The card should be horizontally centered. This is a real-world use case: centering a content card in a page layout.

Centered Card

This 300px card is centered using margin: 20px auto. It has padding, a border, and rounded corners.

Test 8: margin: auto Vertical (Block Context Limitation)

Expected: margin: auto auto (all sides auto) on a block element does NOT vertically center it in normal flow. The box should be horizontally centered but remain at the top of the container. Vertical auto margins compute to 0 in block formatting context.
