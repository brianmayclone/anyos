Expected: Only elements with class="highlighted" should have teal text (#4ecdc4) and a dark teal background. Elements without the class should remain default.

Test 3: ID Selector

Expected: Only the element with id="unique-element" should be golden/yellow (#e2b93d), larger font, bold, with a left border. All other elements should remain default.

This has id="unique-element" - should be golden, large, bold, with left border

This paragraph has no ID - should remain default

This has a different ID - should remain default

Another paragraph without ID - should remain default

Test 4: Universal Selector

Expected: Every child element inside the test area should have a dashed purple border (#9b59b6), 4px margin, and 4px padding. This applies to ALL elements regardless of type.

Paragraph - should have dashed purple border

Span - should have dashed purple border
Div - should have dashed purple border
Strong - should have dashed purple border Em - should have dashed purple border

Test 5: Multiple (Grouped) Selectors

Expected: All h3, h4, and h5 elements should be red (#ff6b6b) and italic. The <p> and <h6> elements should remain default color and style.

Heading 3 - should be red and italic

Heading 4 - should be red and italic

Heading 5 - should be red and italic

Paragraph - should NOT be red or italic (not in selector group)

Heading 6 - should NOT be red or italic (not in selector group)

Test 6: Chained Class Selectors

Expected: ".box" gets dark blue background. ".box.special" gets dark red background with red border and red text. ".box.special.extra" gets dark yellow background with yellow border, yellow text, and bold. Each level of chaining adds specificity.
class="box" - dark blue background, no border
class="box special" - dark red bg, red border, red text
class="box special extra" - dark yellow bg, yellow border, yellow bold text
class="box" again - just dark blue background
class="special" only (no "box") - should NOT get .box.special styling since .box is missing

Test 7: Element + Class Chained Selector

Expected: "p.intro" targets only <p> elements with class="intro" (teal, 18px, bold). "span.intro" targets only <span> elements with class="intro" (red, underlined). Elements that are .intro but wrong element type should not match.

p.intro - should be teal, larger, bold

Plain p - should be default (no .intro class)

span.intro - should be red and underlined
Plain span - should be default
div.intro - should be DEFAULT (neither p.intro nor span.intro matches div)

Test 8: Mixed Selector Types in Grouped Rule

Expected: "div.alert", "p.alert", and "#special-alert" all get the same styling: dark red background, red text, padded. Elements without .alert or the specific ID should remain default.
div.alert - should have red background and text

p.alert - should have red background and text

#special-alert - should have red background and text (matched by ID)

Plain div - should be default

Plain p - should be default

span.alert - should be DEFAULT (rule only targets div.alert and p.alert, not span.alert)
