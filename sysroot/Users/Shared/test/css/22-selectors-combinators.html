Test 5: Deep Nesting - Descendant vs Child Priority

Expected: Direct child spans of .outer should be teal and bold (child combinator, higher specificity for direct). Nested spans deeper inside .outer should be red and underlined (descendant combinator). Both rules have same specificity, but the child rule comes second and applies to direct children.
Direct child span of .outer - should be TEAL and bold (matched by .outer > span, which comes second)
Nested span inside .outer > div - should be RED and underlined (only matched by .outer span)
Another direct child span - should be TEAL and bold
Deeply nested span - should be RED and underlined (descendant only)

Test 6: Chained Combinators (div > ul > li)

Expected: Only <li> elements that are direct children of <ul> which is a direct child of <div> should be golden. Nested <li> inside a sub-list should remain default.
  • Direct li of div > ul - should be GOLDEN
  • Another direct li - should be GOLDEN
  • Third li - should be GOLDEN
    • Nested li inside sub-ul - should be DEFAULT (parent ul is not direct child of div)
    • Another nested li - should be DEFAULT

Test 8: Combinators with Class Selectors

Expected: Direct .item children of .container should have a teal-tinted background. Items with both .item and .active classes (at any depth inside .container) should also have teal text and a left border.
Direct .item child - should have teal-tinted background
Direct .item.active child - should have teal bg + teal text + left border
Another .item - teal-tinted background only
Nested .item (not direct child) - should NOT have teal background (child combinator fails)
Nested .item.active - should have teal text + left border (descendant combinator matches) but NOT teal background
