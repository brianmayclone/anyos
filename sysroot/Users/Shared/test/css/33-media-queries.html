CSS Test 33: Media Queries

Resize the browser window to see media query effects. Tests respond to viewport width changes.

Test 1: @media (min-width: 600px)

Expected: If window width >= 600px: green box saying "Wide viewport detected" is visible, red message is hidden. If window width < 600px: red box saying "Narrow viewport" is visible, green box is hidden. Resize window to test both states.
Wide viewport detected (>= 600px) - This box only appears on wide viewports
Narrow viewport (< 600px) - This box only appears on narrow viewports

Test 2: @media (max-width: 500px)

Expected: If window width <= 500px: yellow box saying "Small viewport" is visible, teal message is hidden. If window width > 500px: teal box saying "Large viewport" is visible, yellow box is hidden. This is the inverse of min-width.
Small viewport (<= 500px) - This box only appears on small viewports
Large viewport (> 500px) - This box only appears on larger viewports

Test 3: Color Changes at Multiple Breakpoints

Expected: A single box that changes color based on viewport width. Under 400px: RED. 400-599px: GOLDEN/YELLOW. 600-799px: GREEN. 800-999px: TEAL. 1000px+: PURPLE. Each breakpoint overrides the previous color. Resize slowly to see all transitions.
Responsive Color Box
<400px=Red | 400px=Yellow | 600px=Green | 800px=Teal | 1000px=Purple

Test 4: Layout Direction Change at Breakpoint

Expected: Below 600px: the three boxes should stack VERTICALLY (flex-direction: column). At 600px and above: the boxes should arrange HORIZONTALLY in a row (flex-direction: row). This is a common responsive pattern for card layouts.

Test 6: @media (prefers-color-scheme)

Expected: The box adapts to the OS color scheme preference. If the system prefers dark mode: darker background with teal border and teal label. If the system prefers light mode: light gray background with dark text and dark border. If no preference is detected, the default dark-themed styling applies.
prefers-color-scheme test
This box changes based on your OS dark/light mode setting.
Dark mode: teal border, very dark bg. Light mode: light bg, dark text.

Test 7: Responsive Font Sizes

Expected: Below 600px: font-size is 14px with 1.4 line-height (compact). 600-899px: font-size is 16px with 1.5 line-height (medium). 900px+: font-size is 18px with 1.6 line-height (comfortable reading). Text should visibly grow as the viewport widens.
This text changes size based on viewport width. At narrow widths it is small and compact (14px). At medium widths it grows slightly (16px). At wide widths it is comfortable reading size (18px). Resize the window to observe the font-size transitions at 600px and 900px breakpoints.

Test 8: Mobile/Desktop Navigation Pattern

Expected: Below 700px: a red "hamburger menu" placeholder is shown (mobile nav), the desktop nav links are hidden. At 700px and above: the desktop navigation links appear in a horizontal row (green), and the mobile nav is hidden. This simulates a responsive navigation bar.
