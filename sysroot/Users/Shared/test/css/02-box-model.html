CSS Test 02: Box Model (Margin, Padding, Border)

Test 1: Individual Margin Properties

Expected: A red box with 30px top margin, 50px right margin, 20px bottom margin, and 40px left margin. The box should be visibly offset from each edge of the gray container.
margin-top: 30px; margin-right: 50px; margin-bottom: 20px; margin-left: 40px

Test 2: Margin Shorthand Variants

Expected: Three boxes. First: 20px margin all sides (1-value). Second: 10px top/bottom, 40px left/right (2-value). Third: 5px top, 30px right, 15px bottom, 50px left (4-value). Containers have dashed borders to show spacing.

1-value shorthand: margin: 20px

margin: 20px (all sides equal)

2-value shorthand: margin: 10px 40px

margin: 10px 40px (TB=10, LR=40)

4-value shorthand: margin: 5px 30px 15px 50px

margin: 5px 30px 15px 50px (T R B L)

Test 3: Margin Auto (Horizontal Centering)

Expected: A 200px wide red box centered horizontally within the container. The left and right margins should be equal.
width: 200px; margin: 0 auto

Test 4: Negative Margins

Expected: First box is normal. Second box has margin-top: -15px, causing it to overlap the first box by 15 pixels. Third box has margin-left: -20px, shifting it 20px to the left beyond the container edge.
Normal box (reference)
margin-top: -15px (overlaps above by 15px)
margin-left: -20px (extends 20px left beyond container)

Test 5: Margin Collapse (Adjacent Siblings)

Expected: Two boxes, first with margin-bottom: 30px, second with margin-top: 20px. The gap between them should be 30px (the larger margin), NOT 50px. Margins collapse to the larger value.
margin-bottom: 30px
margin-top: 20px (collapsed gap should be 30px, not 50px)

Test 6: Margin Collapse (Parent-Child)

Expected: First container has no padding/border, child margin-top: 30px collapses with parent, pushing the entire container down. Second container has padding: 1px, preventing collapse -- the child's margin stays inside.

No padding (collapse occurs):

Child margin-top: 30px (collapses with parent)

With padding: 1px (collapse prevented):

Child margin-top: 30px (stays inside parent)

Test 7: Padding Properties

Expected: First box: individual padding (top 30px, right 50px, bottom 10px, left 40px) -- text offset visibly from each edge. Second box: shorthand padding: 20px (equal all sides). Third box: shorthand padding: 10px 40px (TB=10, LR=40). Background color shows the padding area.
padding-top: 30px, padding-right: 50px, padding-bottom: 10px, padding-left: 40px
padding: 20px (all sides)
padding: 10px 40px (TB=10, LR=40)

Test 8: Border Styles

Expected: Six boxes each with a different border style. Solid = continuous line. Dashed = series of dashes. Dotted = series of dots. Double = two parallel lines. None = no visible border. Ridge = 3D ridged appearance (if supported).
solid
dashed
dotted
double
none
ridge

Test 9: Individual Side Borders

Expected: A box with different borders on each side. Top: 3px solid red. Right: 2px dashed blue. Bottom: 4px dotted green. Left: 3px double orange. Each side should be clearly distinguishable.
border-top: solid red | border-right: dashed blue | border-bottom: dotted green | border-left: double orange

Test 10: Border Shorthand

Expected: First box: border: 2px solid red (shorthand for width + style + color). Second box: border-width: 5px with solid style. Third box: border-color: cyan with 2px solid. The shorthand combines width, style, and color in one declaration.
border: 2px solid red
border-width: 5px
border: 2px solid cyan

Test 11: Explicit Width and Height

Expected: First box is exactly 200px wide and 100px tall. Second box is exactly 300px wide and 50px tall. The red background should fill exactly the specified dimensions (plus padding if any).
200 x 100
300 x 50
