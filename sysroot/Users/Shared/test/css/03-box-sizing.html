CSS Test 03: Box Sizing (content-box vs border-box)

Test 1: content-box vs border-box (Same Declared Width)

Expected: Both boxes declare width: 300px, padding: 20px, border: 5px solid. The CONTENT-BOX (top, red) total rendered width = 300 + 20+20 + 5+5 = 350px. The BORDER-BOX (bottom, blue) total rendered width = 300px (padding and border are included). The orange reference line is exactly 300px wide.

Reference line: 300px wide

content-box: width 300px
Total = 300 + 40 + 10 = 350px
border-box: width 300px
Total = 300px (includes padding + border)

Test 2: Making Both Boxes the Same Visual Width

Expected: The content-box is set to width: 250px (so total = 250 + 40 + 10 = 300px). The border-box is set to width: 300px (total = 300px). Both should appear exactly the same width, aligned with the 300px reference line.

Reference line: 300px wide

content-box: width 250px (visual = 300px)
border-box: width 300px (visual = 300px)

Test 3: Percentage Widths with Box Sizing

Expected: Both boxes declare width: 50%. The content-box (red) at 50% width PLUS its padding and border will exceed 50% of the container. The border-box (blue) at 50% width includes padding and border, so it fits exactly within 50% of the container. The border-box should be visually narrower.
content-box: width 50% + padding 40px + border 10px (overflows 50%)
border-box: width 50% total (fits exactly)

Test 4: No Padding or Border (Both Identical)

Expected: When there is no padding or border, content-box and border-box behave identically. Both boxes should be exactly 300px wide.

Reference line: 300px wide

content-box: 300px (no padding/border)
border-box: 300px (no padding/border)

Test 5: min-width and max-width with Box Sizing

Expected: First box: width: 100px but min-width: 200px, so it renders at 200px. Second box: width: 500px but max-width: 300px, so it renders at 300px. Third box: border-box with width: 300px, min-width: 300px, padding: 20px -- the min-width should refer to the border-box width.

Reference line: 300px wide

width: 100px, min-width: 200px (renders 200px)
width: 500px, max-width: 300px (renders 300px)
border-box: w=300, min-w=300, pad=20, bdr=3

Test 6: Height with Box Sizing

Expected: Both boxes declare height: 100px, padding: 15px, border: 5px. The content-box (red) total height = 100 + 30 + 10 = 140px. The border-box (blue) total height = 100px. The border-box should be visibly shorter.

content-box height: 100px

Total height: 140px

border-box height: 100px

Total height: 100px

Test 7: Nested Containers with border-box

Expected: Outer box is 400px border-box with 20px padding and 2px border. Inner box is width: 100% border-box with 10px padding and 1px border. The inner box should fit exactly within the outer box's content area without overflowing.

Outer: 400px border-box, padding 20px

Inner: width 100% border-box, padding 10px (fits perfectly)

Test 8: Large Padding Relative to Width (border-box)

Expected: A border-box element with width: 200px and padding: 80px on each side. Total horizontal padding (160px) leaves only 40px for content. The box should still render at 200px wide total, with a very narrow content area.
