CSS Test 07: Absolute and Fixed Positioning

Test 1: Absolute Positioned Inside Relative Parent

Expected: The blue box is absolutely positioned at top: 10px, right: 10px WITHIN the gray relative container. It should appear in the top-right corner of the container, not the page. The green flow text should be unaffected by the absolute element (it is removed from flow).

This is the relative parent container (position: relative)

Absolute: top: 10px; right: 10px

Flow content is not affected by the absolute element above.

Test 2: Absolute with top/right/bottom/left

Expected: Four boxes each positioned in a different corner of the relative container. Top-left (red), top-right (blue), bottom-left (green), bottom-right (orange). Each uses the corresponding pair of offsets.
top: 10px; left: 10px
top: 10px; right: 10px
bottom: 10px; left: 10px
bottom: 10px; right: 10px
center reference

Test 3: Absolute Without Any Offset

Expected: The absolute element has NO top/left/right/bottom set. It should appear at the position it would have been in normal flow, but it is removed from flow. The green box below should shift up to fill the space the absolute element would have occupied.
Box 1: static (normal flow)
Box 2: absolute, no offsets (at default position, out of flow)
Box 3: static (moves up because Box 2 is out of flow)

Test 4: Absolute Element Removed From Flow

Expected: Without the absolute element, the three boxes would stack A, B, C. With Box B absolute, Boxes A and C should be adjacent (no gap). Box B is positioned at top: 30px, left: 50% and does not affect the positions of A or C.
Box A: static
Box B: absolute (out of flow)
Box C: static (directly after A)

Test 5: Nested Positioning Contexts

Expected: Outer (red border) is relative. Middle (blue border) is relative, offset 20px from outer. Inner (green) is absolute, positioned top: 0, right: 0 within the MIDDLE container (its nearest positioned ancestor), not the outer. The green box should be in the top-right of the blue-bordered middle container.

Outer (relative, red border)

Middle (relative, blue border, top:20 left:20)

Inner: absolute top:0 right:0 (anchored to middle)

Test 6: position: fixed (Viewport-Relative)

Expected: The purple box in the bottom-right corner of the viewport is position: fixed. It should stay in the same screen position even if you scroll the page. It is positioned relative to the viewport, not any parent element. If scrolling is available, verify it does not move on scroll.

The purple "FIXED" box should be visible in the bottom-right corner of the viewport. It stays fixed to the viewport and does not scroll with the page content.

Note: If the browser does not support position: fixed, the element will behave like static.

FIXED: bottom: 20px; right: 20px

Test 7: z-index Stacking with Absolute Elements

Expected: Three overlapping absolute boxes. Red (z-index: 1) is at the bottom. Green (z-index: 2) is in the middle. Blue (z-index: 3) is on top. The box with the highest z-index should visually cover the others where they overlap.
z-index: 1 (bottom)
z-index: 2 (middle)
z-index: 3 (top)

Test 8: Overlapping Absolute Elements (Source Order)

Expected: Three absolute boxes with NO z-index set. Without z-index, later elements in the source order paint on top of earlier ones. Box 3 (green) should be on top, Box 2 (blue) in the middle, Box 1 (red) at the bottom.
Box 1 (first in source, bottom)
Box 2 (second in source, middle)
Box 3 (third in source, top)

Test 9: Absolute Element Stretching (top + bottom, left + right)

Expected: The blue box has top: 10px, bottom: 10px, left: 10px, right: 10px with NO explicit width/height. It should stretch to fill the container with a 10px margin on all sides. The element's size is determined by the offsets.
Stretched: top/bottom/left/right all 10px (fills container minus 10px inset)
