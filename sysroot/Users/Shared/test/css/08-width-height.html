Test 4: width: auto and height: auto

Expected: width: auto on a block element takes the full available width (same as default). height: auto sizes to fit the content. The first box should stretch full width; the second should be only as tall as needed to contain its text.
width: auto (fills available width for block elements)
height: auto (grows to fit content). This text determines the height.

Test 5: min-width and max-width

Expected: First box: width: 50px, min-width: 150px -- renders at 150px (min wins). Second box: width: 600px, max-width: 300px -- renders at 300px (max wins). Third box: width: 200px, min-width: 100px, max-width: 400px -- renders at 200px (within range). Reference line is 300px.

Reference: 300px

w:600 max-w:300 (renders 300px)

Test 6: min-height and max-height

Expected: First box: little content but min-height: 80px, so it renders at 80px tall even with minimal text. Second box: lots of content but max-height: 60px, so content overflows (overflow: hidden clips it, overflow: auto adds scrollbar). Third box: height: auto with min-height: 50px and adequate content.

Test 7: Percentage Width in Nested Containers

Expected: Outer container is 400px. Inner container is 50% (200px). Innermost box is 50% of its parent (100px). Percentage widths are relative to the parent element's content width, so nesting reduces the effective size.

Outer: 400px

Middle: 50% (200px)

Inner: 50% (100px)

Test 8: 100% Width Behavior

Expected: A box with width: 100% fills the content area of its parent. With padding or border on the child (using content-box), it may overflow. The first child (no padding) fits perfectly. The second child (with padding, content-box) overflows. The third child (border-box) fits.

Parent: 300px, padding: 10px

100% width, no padding (fits)
100% width + padding:10px content-box (overflows)
100% width + padding:10px border-box (fits)

Test 9: height: 100% (Requires Parent Height)

Expected: First case: parent has explicit height: 150px, child height: 100% fills it. Second case: parent has NO explicit height, child height: 100% has no effect (collapses to content height). The child needs an ancestor with a defined height for percentage height to work.

Parent: height: 150px

height: 100% (fills parent)

Parent: NO explicit height

height: 100% (no parent height, collapses)
