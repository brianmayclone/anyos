Test 3: border-radius: 50% (Circle from Square)

Expected: A perfect circle. When border-radius: 50% is applied to a square element (equal width and height), all corners are fully rounded, producing a circle. The three circles should be 60px, 100px, and 140px diameter respectively.

Test 4: Pill Shape (50% or Large Radius on Rectangle)

Expected: When border-radius: 50% is applied to a rectangle (width != height), the result is an ellipse/pill shape. Alternatively, using a very large pixel value (e.g., 999px) on a rectangle produces a pill with fully rounded short sides. Both approaches should produce a smooth capsule/pill shape.
