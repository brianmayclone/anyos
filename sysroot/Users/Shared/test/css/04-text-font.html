font-size: 1.5em (1.5x parent)
font-size: 2rem (2x root element)
font-size: 12pt (approx 16px)
font-size: 150% (1.5x parent)

Expected: Text at different weights. "normal" = 400 weight. "bold" = 700 weight. Numeric values from 100 (thin) to 900 (black/heavy). Not all weights may be available depending on the font; unavailable weights should snap to the nearest available weight.
font-weight: normal (same as 400)
font-weight: bold (same as 700)
font-weight: 100 (thin)
font-weight: 200 (extra light)
font-weight: 300 (light)
font-weight: 400 (normal)
font-weight: 500 (medium)
font-weight: 600 (semi-bold)
font-weight: 700 (bold)

font-weight: 900 (black/heavy)

Test 3: font-style

Expected: "normal" = upright text. "italic" = slanted text (true italic glyphs). "oblique" = mechanically slanted text (if no oblique font, may look similar to italic).
font-style: normal (upright)
font-style: italic (slanted, true italic)
font-style: oblique (mechanically slanted)

Test 4: text-align

Expected: Left = text aligned to left edge. Center = text centered. Right = text aligned to right edge. Justify = text stretched to fill the full width (visible with multi-line text, spaces between words are adjusted).
text-align: left -- This text is aligned to the left edge of the container.
text-align: center -- This text is centered within its container.
text-align: right -- This text is aligned to the right edge of the container.
text-align: justify -- This paragraph has justified text alignment. The spaces between words are adjusted so that both the left and right edges of the text block are aligned. This effect is most visible on lines that are not the last line of a paragraph. Notice how the spacing varies between words to achieve the alignment.

Test 5: text-decoration

Expected: "none" = no decoration (useful for removing link underlines). "underline" = line below text. "overline" = line above text. "line-through" = strikethrough line through the middle of text.
text-decoration: none (no decoration)
text-decoration: underline (line below)
text-decoration: overline (line above)
text-decoration: line-through (strikethrough)
text-decoration: underline overline (both)

Test 6: text-transform

Expected: "uppercase" = all letters uppercase. "lowercase" = all letters lowercase. "capitalize" = first letter of each word uppercase. "none" = text as written in HTML source.
text-transform: none -- This Text Stays As Written
text-transform: uppercase -- this should all be uppercase
text-transform: lowercase -- THIS SHOULD ALL BE LOWERCASE
text-transform: capitalize -- each word starts with a capital letter

Test 7: text-indent

Expected: First paragraph has no indent (default). Second has 40px indent on the first line only. Third has 80px indent. The indent only applies to the first line of each block.
text-indent: 0 -- This paragraph has no indentation. The first line starts at the normal position.
text-indent: 40px -- This paragraph's first line is indented 40 pixels. Subsequent lines wrap normally to the left edge. Only the first line is affected by text-indent.
text-indent: 80px -- This paragraph's first line is indented 80 pixels. This is a larger indent, commonly used in print-style typography.

Test 8: line-height

Expected: Each block has different spacing between lines. "normal" = browser default (~1.2). "1" = tight (no extra space, lines may touch). "2" = double-spaced. "24px" = fixed 24px line height. "200%" = 2x font-size.
line-height: normal -- This text has the default line-height. Multiple lines of text should have standard spacing between baselines. This is typically about 1.2 times the font size.
line-height: 1 -- Tight spacing. Lines may overlap or touch. This text demonstrates a line-height equal to the font-size with no additional leading between lines.
line-height: 2 -- Double-spaced text. There is significant space between each line. This is useful for readability in certain contexts.
line-height: 30px -- Fixed 30px line height regardless of font size. Each line occupies exactly 30 pixels of vertical space.
line-height: 1.5em -- 1.5 times the font-size. This is a comfortable reading line-height used in many designs.
line-height: 200% -- Double the font-size. Same visual effect as line-height: 2, specified as a percentage.

Test 9: white-space

Expected: "normal" = collapses whitespace, wraps text. "nowrap" = collapses whitespace, no wrapping (single line, may overflow). "pre" = preserves whitespace and newlines, no wrapping. "pre-wrap" = preserves whitespace and newlines, wraps. "pre-line" = collapses spaces but preserves newlines, wraps.

Source text has extra spaces and newlines inside.

white-space: normal -- Multiple spaces collapse and newlines are treated as spaces. Text wraps normally at the container edge.
white-space: nowrap -- Multiple spaces collapse and text does not wrap. This line will extend beyond the container if long enough.
white-space: pre Spaces are preserved. Newlines are preserved. No wrapping occurs.
white-space: pre-wrap Spaces are preserved. Newlines are preserved. But text wraps at the container edge if the line is too long for the available space.
white-space: pre-line Spaces collapse to single. But newlines ARE preserved. Text wraps normally at the container edge.

Expected: First box: a very long word overflows the container (default). Second box: overflow-wrap: break-word causes the long word to break and wrap within the container.
Default: Supercalifragilisticexpialidociousandthensome overflows.
overflow-wrap: break-word: Supercalifragilisticexpialidociousandthensome wraps.

Test 11: letter-spacing

Expected: "normal" = default letter spacing. Positive values increase spacing between each character. Negative values decrease spacing (letters closer together or overlapping).
letter-spacing: normal -- Default character spacing
letter-spacing: 2px -- Slightly expanded spacing
letter-spacing: 5px -- Wide spacing between characters
letter-spacing: 10px -- Very wide spacing
letter-spacing: -1px -- Slightly condensed spacing
