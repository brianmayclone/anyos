CSS Test 31: List Styling

Test 1: list-style-type: disc (Default UL)

Expected: Each list item should have a filled circle (disc) as its bullet marker. This is the default style for unordered lists.
  • Item with disc marker (filled circle)
  • Second item with disc marker
  • Third item with disc marker
  • Fourth item with disc marker

Test 2: list-style-type: circle

Expected: Each list item should have an open circle (unfilled ring) as its bullet marker, distinct from the filled disc.
  • Item with circle marker (open/unfilled circle)
  • Second item with circle marker
  • Third item with circle marker
  • Fourth item with circle marker

Test 3: list-style-type: square

Expected: Each list item should have a filled square as its bullet marker.
  • Item with square marker (filled square)
  • Second item with square marker
  • Third item with square marker
  • Fourth item with square marker

Test 4: list-style-type: decimal (Default OL)

Expected: Items should be numbered with decimal numbers: 1, 2, 3, 4, 5. This is the default style for ordered lists.
  1. First item (1.)
  2. Second item (2.)
  3. Third item (3.)
  4. Fourth item (4.)
  5. Fifth item (5.)

Test 5: list-style-type: lower-alpha

Expected: Items should be labeled with lowercase letters: a, b, c, d, e, f.
  1. First item (a.)
  2. Second item (b.)
  3. Third item (c.)
  4. Fourth item (d.)
  5. Fifth item (e.)
  6. Sixth item (f.)

Test 6: list-style-type: upper-alpha

Expected: Items should be labeled with uppercase letters: A, B, C, D, E, F.
  1. First item (A.)
  2. Second item (B.)
  3. Third item (C.)
  4. Fourth item (D.)
  5. Fifth item (E.)
  6. Sixth item (F.)

Test 7: list-style-type: lower-roman

Expected: Items should be labeled with lowercase Roman numerals: i, ii, iii, iv, v, vi, vii, viii, ix, x.
  1. First item (i.)
  2. Second item (ii.)
  3. Third item (iii.)
  4. Fourth item (iv.)
  5. Fifth item (v.)
  6. Sixth item (vi.)
  7. Seventh item (vii.)
  8. Eighth item (viii.)
  9. Ninth item (ix.)
  10. Tenth item (x.)

Test 8: list-style-type: upper-roman

Expected: Items should be labeled with uppercase Roman numerals: I, II, III, IV, V, VI, VII, VIII, IX, X.
  1. First item (I.)
  2. Second item (II.)
  3. Third item (III.)
  4. Fourth item (IV.)
  5. Fifth item (V.)
  6. Sixth item (VI.)
  7. Seventh item (VII.)
  8. Eighth item (VIII.)
  9. Ninth item (IX.)
  10. Tenth item (X.)

Test 9: list-style-type: none

Expected: No bullet markers should appear at all. The items should still be indented by the list padding, but there should be no disc, circle, number, or any other marker before each item.
  • Item with no marker (list-style-type: none)
  • Second item - no marker
  • Third item - no marker
  • Fourth item - no marker

Test 10: Nested Lists with Different Styles

Expected: Three levels of nesting. Level 1 (outermost) uses disc (filled circle). Level 2 uses circle (open circle). Level 3 (innermost) uses square (filled square). Each level should show its distinct marker style.
  • Level 1 - disc marker (filled circle)
    • Level 2 - circle marker (open circle)
      • Level 3 - square marker (filled square)
      • Level 3 - square marker
    • Level 2 - circle marker
  • Level 1 - disc marker
    • Level 2 - circle marker
      • Level 3 - square marker
  • Level 1 - disc marker (no children)

Test 11: Mixed Ordered List Styles (Nested OL)

Expected: An outline-style list with three nesting levels. Level 1 uses upper-roman (I, II, III). Level 2 uses lower-alpha (a, b, c). Level 3 uses decimal (1, 2, 3). This simulates a document outline format.
  1. Chapter One (I.)
    1. Section A (a.)
      1. Point 1 (1.)
      2. Point 2 (2.)
      3. Point 3 (3.)
    2. Section B (b.)
      1. Point 1 (1.)
      2. Point 2 (2.)
  2. Chapter Two (II.)
    1. Section A (a.)
    2. Section B (b.)
    3. Section C (c.)
  3. Chapter Three (III.)
    1. Section A (a.)
