CSS Test 06: Static and Relative Positioning

Test 1: position: static (Default Flow)

Expected: Three block boxes stacked vertically in normal document flow. Each takes the full width and sits directly below the previous one. The top/left/right/bottom/z-index properties have NO effect on static elements. Box 2 has top: 50px set but it should NOT move.
Box 1: position: static (default)
Box 2: position: static + top: 50px, left: 50px (IGNORED, should NOT move)
Box 3: position: static (default)

Test 2: position: relative with top/left Offsets

Expected: Box 2 is relatively positioned with top: 20px and left: 30px. It should visually shift DOWN 20px and RIGHT 30px from its normal position. The original space it occupied in the flow is PRESERVED -- Box 3 stays in its normal position as if Box 2 had not moved.
Box 1: static (reference)
Box 2: position: relative; top: 20px; left: 30px (shifted from original spot)
Box 3: static (position unchanged, gap remains where Box 2 was)

Test 3: position: relative with Negative Offsets

Expected: Box 2 has top: -15px and left: -10px. It shifts UP 15px and LEFT 10px from its normal position, overlapping Box 1 and extending beyond the container's left padding. The original space in the flow is still preserved.
Box 1: static (reference)
Box 2: relative; top: -15px; left: -10px (shifts up and left, overlaps Box 1)
Box 3: static (gap preserved above)

Test 4: Relative Positioning Preserves Original Space

Expected: Box B is moved far away (top: 60px, left: 100px) but its original space between Box A and Box C is preserved. There should be a visible empty gap between A and C where B normally would be. B appears visually displaced but the layout is unchanged.
Box A: static
Box B: relative; top: 60px; left: 100px (far from origin but space kept)
Box C: static (gap above is where B was in normal flow)
Box D: static

Test 5: Relative Positioning with z-index (Layering)

Expected: Three overlapping boxes using relative positioning. Box 1 (red) z-index: 1. Box 2 (blue) z-index: 3 (on top). Box 3 (green) z-index: 2 (between). Box 2 should be visually on top of all others. The z-index only works on positioned elements (not static).
Box 1: z-index: 1 (bottom)
Box 2: z-index: 3 (top)
Box 3: z-index: 2 (middle)

Test 6: z-index on Static Elements (No Effect)

Expected: Box 1 has position: static with z-index: 999 -- the z-index should be IGNORED because z-index only applies to positioned elements. Box 2 (relative, z-index: 1) should still overlap Box 1 when it shifts up, appearing on top despite the lower z-index number.
Box 1: static, z-index: 999 (ignored!)
Box 2: relative, z-index: 1 (appears on top)

Test 7: Using bottom and right Offsets

Expected: "bottom: 20px" moves the element UP by 20px (opposite of top). "right: 30px" moves it LEFT by 30px (opposite of left). Box 2 should shift UP and LEFT from its normal position.
Box 1: static (reference)
Box 2: relative; bottom: 20px; right: 30px (shifts up 20px and left 30px)
Box 3: static (normal flow position)

Test 8: Relative Positioning on Inline Elements

Expected: The highlighted word "shifted" should be visually displaced (down 5px, right 10px) from its normal inline position, but the surrounding text should not reflow -- the space for the word should remain in the text line.

This is normal text with a shifted word in the middle. Notice the gap where the word was originally positioned, while the word itself appears displaced.

Test 9: Nested Relative Positioning

Expected: Outer box is relative with top: 20px, left: 20px. Inner box is relative with top: 10px, left: 10px. The inner box shifts relative to its own normal position (which is already inside the shifted outer box). Total visual offset of inner content from original flow: approximately 30px down and 30px right.
Reference: static box
Outer: relative top:20 left:20
Inner: relative top:10 left:10 (shifts relative to its own normal position)
