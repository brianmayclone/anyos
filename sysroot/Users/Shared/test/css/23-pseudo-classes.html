Test 1: :first-child and :last-child

Expected: The first list item should be red and bold (:first-child). The last list item should be teal and bold (:last-child). Middle items should remain default color.
  • First item - should be RED and bold (:first-child)
  • Second item - should be DEFAULT
  • Third item - should be DEFAULT
  • Fourth item - should be DEFAULT
  • Fifth item (last) - should be TEAL and bold (:last-child)

Test 2: :nth-child(n), :nth-child(odd), :nth-child(even)

Expected: Odd items (1st, 3rd, 5th) get a golden left border. Even items (2nd, 4th, 6th) get a purple left border. The 2nd item specifically also gets red text with a dark red background.
  • Item 1 (odd) - golden left border
  • Item 2 (even + nth-child(2)) - purple left border + RED text + dark red bg
  • Item 3 (odd) - golden left border
  • Item 4 (even) - purple left border
  • Item 5 (odd) - golden left border
  • Item 6 (even) - purple left border

Test 3: :nth-child(3n) and :nth-child(2n+1)

Expected: Every 3rd item (3, 6, 9) should be red and bold (:nth-child(3n)). Every odd item (1, 3, 5, 7, 9) should be italic (:nth-child(2n+1)). Item 3 and 9 match both rules (red, bold, italic).
  • Item 1: 2n+1=yes, 3n=no - ITALIC only
  • Item 2: 2n+1=no, 3n=no - DEFAULT
  • Item 3: 2n+1=yes, 3n=yes - RED BOLD ITALIC
  • Item 4: 2n+1=no, 3n=no - DEFAULT
  • Item 5: 2n+1=yes, 3n=no - ITALIC only
  • Item 6: 2n+1=no, 3n=yes - RED BOLD only
  • Item 7: 2n+1=yes, 3n=no - ITALIC only
  • Item 8: 2n+1=no, 3n=no - DEFAULT
  • Item 9: 2n+1=yes, 3n=yes - RED BOLD ITALIC

Expected: The last item (:nth-last-child(1)) should be teal and bold. The second-to-last item (:nth-last-child(2)) should be golden/yellow.

  • Item 2 - should be DEFAULT
  • Item 3 - should be DEFAULT
  • Item 4 - second-to-last - should be GOLDEN (:nth-last-child(2))

Expected: The first <p> should be red and bold. The last <p> should be teal and italic. The first <span> should be golden and underlined. Other elements of the same type should be default. Note: :first-of-type considers element type within the parent, not position among all children.

First paragraph - should be RED and bold (:first-of-type for p)

Second span - should be DEFAULT

Middle paragraph - should be DEFAULT

Last paragraph - should be TEAL and italic (:last-of-type for p)

Third span - should be DEFAULT (not first-of-type)
