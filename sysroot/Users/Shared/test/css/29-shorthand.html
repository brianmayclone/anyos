CSS Test 29: Shorthand Property Expansion

Test 1: margin: 20px (1 value - all sides)

Expected: The box should have 20px margin on ALL four sides (top, right, bottom, left). The gap between the box and the container edge should be uniform.
margin: 20px - 20px on all four sides. Equal spacing all around.

Test 2: margin: 10px 40px (2 values - vertical horizontal)

Expected: The box should have 10px margin on top and bottom, and 40px margin on left and right. Horizontal spacing should be noticeably wider than vertical spacing.
margin: 10px 40px - 10px top/bottom, 40px left/right. Wider horizontal gap.

Test 3: margin: 10px 30px 50px (3 values - top horizontal bottom)

Expected: The box should have 10px top margin, 30px left and right margin, and 50px bottom margin. Bottom spacing should be noticeably larger than top.
margin: 10px 30px 50px - 10px top, 30px left/right, 50px bottom. Large bottom gap.

Test 4: margin: 10px 20px 30px 40px (4 values - TRBL)

Expected: The box should have Top=10px, Right=20px, Bottom=30px, Left=40px margin (clockwise from top). The left margin should be the largest, making the box visibly offset to the right.
margin: 10px 20px 30px 40px - T:10, R:20, B:30, L:40. Offset right due to large left margin.

Test 5: Padding Shorthand (Same Patterns as Margin)

Expected: Four boxes with different padding shorthands. p1: uniform 20px padding. p2: 10px top/bottom, 40px left/right (wide box). p3: 10px top, 30px sides, 50px bottom. p4: 10/20/30/40 clockwise. Padding is visible as the space between border and text.
padding: 20px (all)
padding: 10px 40px (v/h)
padding: 10px 30px 50px (t/h/b)
padding: 10px 20px 30px 40px (TRBL)

Test 6: Border Shorthand

Expected: First box: 3px solid red border. Second: 2px dashed teal border. Third: 4px dotted golden border. Fourth: 2px solid purple on most sides BUT a 6px solid red left border (longhand override). Border shorthand sets width + style + color in one declaration.
border: 3px solid red
border: 2px dashed teal
border: 4px dotted golden
border: 2px solid purple + border-left: 6px solid red (longhand override on left side)

Test 7: Background Shorthand

Expected: First box has a solid dark red background from the shorthand. Second box has a solid dark green background. Background shorthand can include color, image, position, repeat, and size, but here we test color-only shorthand.
background: #3a1a2a (dark red background color via shorthand)
background: #1a3a1a (dark green background color via shorthand)

Test 8: Flex Shorthand

Expected: Row 1: flex:1 and flex:2 boxes. The flex:2 box should be TWICE as wide as the flex:1 box. Row 2: flex:0 0 100px (fixed 100px, won't grow/shrink) next to flex:1 1 auto (takes remaining space).
flex: 1 (1 share)
flex: 2 (2 shares - TWICE as wide as flex:1)
flex: 0 0 100px (fixed)
flex: 1 1 auto (fills remaining space)
flex: 1
flex: 1
flex: 1 (three equal columns)

Test 9: Font Shorthand

Expected: First line: italic bold 18px sans-serif. Second line: 14px with 1.8 line-height (generous spacing between lines). Third line: bold 24px sans-serif (large and bold). The font shorthand combines style, weight, size/line-height, and family.
font: italic bold 18px sans-serif - should be italic, bold, 18px
font: 14px/1.8 sans-serif - should be 14px with generous line spacing (1.8 line-height).
This second line tests the line-height. There should be visible extra space between these two lines.
font: bold 24px sans-serif - should be bold, 24px (large)

Test 10: Longhand Properties After Shorthand (Override)

Expected: First box: margin shorthand sets all sides to 20px, then margin-left longhand overrides to 50px. The left margin should be visibly larger. Second box: border shorthand sets 3px solid red on all sides, then border-top-color overrides to teal, and border-bottom-width to 6px. Top border should be teal (not red), and bottom border should be thicker (6px).
margin: 20px + margin-left: 50px - left margin is 50px, others are 20px
border: 3px solid red + border-top-color: teal + border-bottom-width: 6px
