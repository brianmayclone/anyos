CSS Test 26: CSS Inheritance

Test 1: Inherited Property - color

Expected: The parent has color: red. All child elements (span, strong, em, nested div) should INHERIT the red color without explicitly setting it. Color is an inherited property.
Parent text is RED. Span child - should INHERIT red | Strong child - should INHERIT red | Em child - should INHERIT red
Nested div child - should INHERIT red

Nested paragraph grandchild - should INHERIT red

Test 2: Inherited Properties - font-size, font-weight, font-style, line-height

Expected: The parent has font-size: 20px, font-weight: bold, font-style: italic, line-height: 1.8. All children should inherit these font properties, appearing as 20px bold italic text with generous line spacing.
Parent text: 20px, bold, italic, line-height 1.8
Child span - should inherit all font properties (20px, bold, italic)

Child paragraph - should inherit all font properties (20px, bold, italic, line-height 1.8)

Test 3: Inherited Property - text-align

Expected: The first parent has text-align: center. All children inside it should be centered. The second parent has text-align: right. All children inside it should be right-aligned. text-align is inherited.
Parent: text-align center

Child paragraph - should be CENTERED (inherits text-align)

Grandchild span - should be CENTERED (inherits text-align)
Parent: text-align right

Child paragraph - should be RIGHT-ALIGNED (inherits text-align)

Grandchild span - should be RIGHT-ALIGNED (inherits text-align)

Test 4: Non-Inherited Properties (background, margin, padding, border, width, height)

Expected: The parent has background (dark red), margin (10px), padding (15px), border (3px solid red), width (80%), height (100px). The child should NOT inherit any of these - it should have transparent background, no margin, no padding, no border, auto width, auto height.
Parent: has background, margin, padding, border, width, height
Child: should NOT inherit background (transparent), margin (0), padding (small explicit), border (none), width (auto), height (auto). The child sits inside the parent but does not replicate parent's box properties.

Test 5: The "inherit" Keyword

Expected: The parent has a teal border (3px solid), padding (15px), and teal background. The child uses "inherit" for border, padding, and background - forcing these normally non-inherited properties to copy from the parent. The child should have the SAME border, padding, and background as the parent.
Parent: 3px solid teal border, 15px padding, teal-tinted background
Child with border: inherit; padding: inherit; background: inherit;
Should have the SAME teal border, padding, and background as parent.

Test 6: The "initial" Keyword

Expected: The parent has red color, bold weight, 20px size. The child uses "initial" for all three properties, resetting them to their CSS initial values: color becomes black (initial), font-weight becomes normal (initial = 400), font-size becomes medium (initial, typically 16px). The child should look visually different from the parent.
Parent: RED, bold, 20px
Child with color/font-weight/font-size: initial - should be DEFAULT color (black/dark), normal weight, medium (~16px) size. Looks different from parent.
Normal child (no initial) - should INHERIT red, bold, 20px from parent

Test 7: Deep Nesting - Grandchild Inherits from Grandparent

Expected: Grandparent sets color (golden), font-size (18px), font-weight (bold), and border (non-inherited). The middle parent adds NO color/font styles. The grandchild should inherit golden color, 18px size, and bold weight from grandparent through the middle parent. The border should NOT propagate.
Grandparent: golden color, 18px, bold, golden border
Middle parent: no explicit color/font styles (inherits golden, 18px, bold). Has its own dashed border (NOT inherited from grandparent).
Grandchild: should inherit GOLDEN color, 18px, bold from grandparent through middle parent. Has its own green background and border-radius (non-inherited properties set directly). No golden border (border does not inherit).

Test 8: Inheritance vs Direct Styling Override

Expected: The ancestor sets color (red), font-size (22px), font-weight (bold). The descendant overrides ONLY color to teal. The font-size (22px) and font-weight (bold) should still be inherited since they are not overridden. Direct styles on an element always beat inherited values.
Ancestor: RED, 22px, bold
Descendant: overrides color to TEAL, but inherits 22px and bold from ancestor. Should be TEAL, 22px, bold.
Normal descendant (no override): should inherit RED, 22px, bold
