CSS Test 27: CSS Custom Properties (Variables)

Test 1: Basic Custom Properties on :root

Expected: Three text elements using var(--primary-color) = red, var(--secondary-color) = teal, and var(--accent-color) = golden. Each should display in its respective color, bold.
Using var(--primary-color) - should be RED (#ff6b6b)
Using var(--secondary-color) - should be TEAL (#4ecdc4)
Using var(--accent-color) - should be GOLDEN (#e2b93d)

Test 2: Fallback Values

Expected: First element uses var(--nonexistent-color, #9b59b6) - since --nonexistent-color is undefined, the fallback PURPLE should be used. Second element uses var(--primary-color) which exists, so it should be RED. Third uses a nested fallback: var(--also-nonexistent, var(--secondary-color)) which should resolve to TEAL.
var(--nonexistent-color, #9b59b6) - variable undefined, fallback to PURPLE
var(--primary-color) - variable defined, should be RED (no fallback needed)
var(--also-nonexistent, var(--secondary-color)) - nested fallback, should be TEAL

Test 3: Overriding Variables in Child Scope

Expected: The parent scope defines --scope-color as red and --scope-bg as dark red. Inside the .scope-child-override element, these are overridden to teal and dark teal. Elements in the parent scope should be red on dark red. Elements in the child scope should be teal on dark teal.
In parent scope: --scope-color = RED, --scope-bg = dark red
Still in parent scope: RED on dark red
In child override scope: --scope-color = TEAL, --scope-bg = dark teal
Still in child scope: TEAL on dark teal
Back in parent scope: RED on dark red (override is scoped to child)

Test 4: Multiple Variables in One Declaration

Expected: A single element using four different custom properties: padding from --spacing (12px), font-size from --font-lg (20px), color from --accent-color (golden), and border from --border-style (2px solid teal). All should resolve and render correctly together.
Using four variables: padding=var(--spacing), font-size=var(--font-lg), color=var(--accent-color), border=var(--border-style).
Should be: 12px padding, 20px font, GOLDEN text, 2px solid teal border.

Test 5: Variable Referencing Another Variable

Expected: --ref-color is defined as var(--primary-color) on :root. Using var(--ref-color) should resolve through the chain to the value of --primary-color, which is red (#ff6b6b). Text should be RED, 18px, bold.
var(--ref-color) which is var(--primary-color) = should be RED (#ff6b6b), 18px, bold

Test 6: Variables in calc() Expressions

Expected: First box uses calc(var(--box-width) - var(--gutter) * 2) for width = calc(200px - 20px) = 180px, with 10px padding. Second line uses calc(var(--base-size) * 1.5) for font-size = 24px. Both should render at computed sizes.
Width: calc(var(--box-width) - var(--gutter) * 2) = 180px wide with 10px padding
Font-size: calc(var(--base-size) * 1.5) = 24px - should be noticeably larger, GOLDEN, bold

Test 7: Variables for Theming

Expected: Three cards, each with a different "theme" achieved by overriding the same custom property names in different scopes. Default theme: light gray text, dark blue bg, gray border, teal accent. Warm theme: warm yellow text, brown bg, golden border, red accent. Cool theme: light blue text, navy bg, teal border, purple accent.
Default Theme - gray text, dark blue bg, gray border. Accent text is TEAL.
Warm Theme - warm yellow text, brown bg, golden border. Accent text is RED.
Cool Theme - light blue text, navy bg, teal border. Accent text is PURPLE.

Test 8: Variables for Spacing System

Expected: Five boxes with increasing padding values from the spacing custom properties: --space-xs (4px), --space-sm (8px), --space-md (16px), --space-lg (24px), --space-xl (32px). Each box should be visibly larger due to more padding.
XS (4px padding)
SM (8px padding)
MD (16px padding)
LG (24px padding)
XL (32px padding)
