CSS Test 24: Attribute Selectors

Test 1: [attr] - Has Attribute

Expected: Any element with a data-status attribute (regardless of value) should have a red left border and red text. Elements without data-status should remain default.
Has data-status="active" - should be RED
No data-status attribute - should be DEFAULT
Has data-status="inactive" - should be RED
Has data-status="" (empty) - should STILL be RED (attribute exists)
No data-status attribute - should be DEFAULT
Has data-status="pending" - should be RED

Test 2: [attr=value] - Exact Match

Expected: data-role="admin" should be red and bold with red left border. data-role="user" should be teal with teal left border. Other values or no attribute should be default.
data-role="admin" - should be RED and bold
data-role="user" - should be TEAL
data-role="moderator" - should be DEFAULT (no exact match)
data-role="admin user" - should be DEFAULT (exact match only, not "admin")
No data-role - should be DEFAULT
data-role="user" - should be TEAL

Test 3: [attr~=value] - Contains Word (Space-Separated)

Expected: Elements whose data-tags attribute contains the word "important" (as a space-separated word) should be golden and bold. The word must be complete - "important" inside "unimportant" should NOT match.
data-tags="important urgent" - should be GOLDEN (contains word "important")
data-tags="low priority" - should be DEFAULT
data-tags="urgent important review" - should be GOLDEN
data-tags="unimportant" - should be DEFAULT ("important" is substring, not whole word)
data-tags="important" - should be GOLDEN (single word match)
No data-tags - should be DEFAULT

Test 4: [attr^=value] - Starts With

Expected: Links starting with "https" should be teal and bold. Links starting with "http:" (not https) should be red. Other protocols or no href should be default.
https://example.com - should be TEAL and bold (starts with "https")
https://secure.site.com - should be TEAL and bold
http://insecure.com - should be RED (starts with "http:")
ftp://files.com - should be DEFAULT (starts with neither)
https://another.com/page - should be TEAL and bold
mailto:test@test.com - should be DEFAULT

Test 5: [attr$=value] - Ends With

Expected: Links ending in ".pdf" should be red and bold. Links ending in ".html" should be teal. Links ending in ".jpg" should be golden. Other extensions should be default.
report.pdf - should be RED and bold (ends with .pdf)
about.html - should be TEAL (ends with .html)
photo.jpg - should be GOLDEN (ends with .jpg)
data.csv - should be DEFAULT (no matching extension)
manual.pdf - should be RED and bold
logo.png - should be DEFAULT (no matching extension)
index.html - should be TEAL

Test 6: [attr*=value] - Contains Substring

Expected: Elements whose data-info contains "error" anywhere should have red text and dark red background. Elements whose data-info contains "success" should have green text and dark green background. Others should be default.
data-info="error-404" - should be RED (contains "error")
data-info="success-created" - should be GREEN (contains "success")
data-info="warning-low" - should be DEFAULT
data-info="fatal-error-crash" - should be RED (contains "error")
data-info="partial-success-rate" - should be GREEN (contains "success")
data-info="info-message" - should be DEFAULT

Test 7: [attr|=value] - Value or Value-Prefix (Hyphen-Separated)

Expected: lang="en" or lang="en-*" (e.g. en-US, en-GB) should be teal. lang="fr" or lang="fr-*" should be red. lang="de" or lang="de-*" should be golden. This matches the value exactly OR the value followed by a hyphen.
lang="en" - should be TEAL
lang="en-US" - should be TEAL (en followed by hyphen)
lang="en-GB" - should be TEAL
lang="fr" - should be RED
lang="fr-CA" - should be RED
lang="de" - should be GOLDEN
lang="de-AT" - should be GOLDEN
lang="es" - should be DEFAULT (no matching rule)
lang="english" - should be DEFAULT (does not match en|=)

Test 8: Multiple Attribute Selectors Combined

Expected: Text inputs with [required] should have a red border and dark red background. Text inputs WITHOUT [required] should have a teal border and dark teal background. Non-text inputs should be default.

Test 9: Case-Insensitive Attribute Selector [attr=value i]

Expected: The [data-value="Hello" i] selector matches case-insensitively. Elements with data-value of "Hello", "hello", "HELLO", or "hElLo" should all be purple and bold. Note: The "i" flag for case-insensitive matching may not be supported in all browsers.
data-value="Hello" - should be PURPLE (exact match)
data-value="hello" - should be PURPLE (case-insensitive "i" flag)
data-value="HELLO" - should be PURPLE (case-insensitive)
data-value="hElLo" - should be PURPLE (case-insensitive)
data-value="World" - should be DEFAULT (different word)
data-value="HelloWorld" - should be DEFAULT (not exact match)
