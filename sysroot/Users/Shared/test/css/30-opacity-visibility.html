Test 4: display:none vs visibility:hidden Comparison

Expected: In the first group, Item B has display:none - it is completely removed from layout. Items A and C should be adjacent with no gap. In the second group, Item E has visibility:hidden - it is invisible but its space is preserved. Items D and F should have a visible gap between them.

Item E - visibility:hidden (invisible but space remains)
Item F - visible (should have a gap above where E is)

Test 5: Opacity on Parent Affecting Children

Expected: When opacity is set on a parent, ALL children are also affected. The child cannot be MORE opaque than the parent. Parent at opacity:1 = child fully visible. Parent at opacity:0.5 = both parent and child are half-transparent. Parent at opacity:0.25 = both are very faint.

Test 8: visibility:hidden Parent with visibility:visible Child

Expected: The parent has visibility:hidden (invisible, but space preserved). The child inside it has visibility:visible, which OVERRIDES the parent's hidden state for that child only. The parent's border (red) should NOT be visible, but the child (green box with teal text) SHOULD be visible. This is different from opacity - a child CAN override visibility:hidden.
