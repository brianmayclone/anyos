CSS Test 25: Specificity and Cascade

Test 1: Element Selector vs Class Selector

Expected: The plain paragraph uses element selector (specificity 0,0,1) and should be red. The paragraph with class="highlight" uses class selector (specificity 0,1,0) which WINS, so it should be teal. Class beats element.

No class - element selector wins - should be RED

Has class="highlight" - class selector WINS over element - should be TEAL

Element selector: specificity (0,0,1) | Class selector: specificity (0,1,0)

Test 2: Class Selector vs ID Selector

Expected: The element with only class="styled" should be red (class specificity 0,1,0). The element with id="special" should be teal (ID specificity 1,0,0 WINS over class). ID beats class.
class="styled" only - class selector - should be RED
class="styled" AND id="special" - ID selector WINS - should be TEAL
Class selector: specificity (0,1,0) | ID selector: specificity (1,0,0)

Test 3: ID Selector vs Inline Style

Expected: The ID selector sets color to red and font-size 20px. The inline style overrides color to golden (inline specificity beats ID). Font-size stays 20px from the ID rule since inline doesn't set it. Inline style beats ID.
id="inline-test" + style="color: golden" - INLINE WINS for color - should be GOLDEN, 20px font
ID selector: specificity (1,0,0) | Inline style: specificity (1,0,0,0) - highest

Test 4: Multiple Classes Increasing Specificity

Expected: Single class .item = red (0,1,0). Two classes .item.special = teal (0,2,0, wins). Three classes .item.special.featured = golden (0,3,0, wins). More classes = higher specificity.
class="item" - single class (0,1,0) - should be RED
class="item special" - two classes (0,2,0) - should be TEAL
class="item special featured" - three classes (0,3,0) - should be GOLDEN
Specificity: .item = (0,1,0) | .item.special = (0,2,0) | .item.special.featured = (0,3,0)

Test 5: !important Overriding Everything

Expected: The element has an ID selector (red, specificity 1,0,0) AND a class with !important (teal). The !important flag OVERRIDES even ID specificity. Text should be TEAL.
id="important-test" (red) vs class with !important (teal) - !important WINS - should be TEAL
ID selector (1,0,0) loses to .important-class with !important

Test 6: Same Specificity - Last Rule Wins (Source Order)

Expected: Two rules with identical selectors (.demo). Both have specificity (0,1,0). The LAST rule in source order wins for the color property (teal). The first rule's font-weight (bold) is NOT overridden by the second rule, so text should be teal AND bold.
Two identical selectors - last color wins - should be TEAL and BOLD
First rule: color red + bold | Second rule: color teal (no font-weight) | Result: teal + bold

Test 7: Specificity Calculation Examples

Expected: For .calc-a, both rules have same specificity (0,1,1 counting .test-area.test-calc context), so last rule wins: RED. For .calc-b, ".container p.calc-b" has higher specificity (extra class) than "p.calc-b", so TEAL wins even though the red rule comes later in source.

p.calc-a - same specificity rules, last one wins - should be RED

.container p.calc-b (0,2,1) vs p.calc-b (0,1,1) - higher specificity wins - should be TEAL

.calc-a: both (0,1,1) = last wins | .calc-b: (0,2,1) beats (0,1,1) = higher specificity wins

Test 8: Combined Specificity Battle

Expected: The first span is inside a p in .test-battle - only the element+class rule applies, so RED. The second span is inside p.winner - the .winner class rule (0,2,1) beats the element rule (0,1,3), so TEAL and bold. The third span has an ID - the ID rule (1,0,1) beats everything, so GOLDEN, bold, underlined.

Span in plain p - element-heavy selector (0,1,3) only - should be RED

Span in p.winner - class-heavy selector (0,2,1) WINS over (0,1,3) - should be TEAL, bold

Span in #battle-id - ID selector (1,0,1) WINS over all - should be GOLDEN, bold, underlined

div.test-area p span = (0,1,3) | .test-battle .winner span = (0,2,1) | #battle-id span = (1,0,1)
